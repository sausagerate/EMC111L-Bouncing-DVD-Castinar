# Bouncing DVD Screen (Three.js)

Theo Paulo Castinar — EMC111L.A224

The DVD logo starts at `(0, 0, 0)` in an 800 × 800 scene. It changes color and shrinks when it touches a wall. It disappears on the seventh bounce.

## Run

Open this folder in GitHub Codespaces or Cursor. In the terminal, run:

```bash
python3 -m http.server 8000
```

Open the forwarded port 8000 in Codespaces, or open `http://localhost:8000` on your computer. An internet connection is needed to load Three.js from the CDN.

Submit the URL of the GitHub repository containing these files.
